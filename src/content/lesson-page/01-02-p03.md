No todos los problemas con LaTeX son iguales. Es importante distinguir dos tipos:

- **Error de sintaxis:** el código contiene algo mal escrito que impide la compilación. El sistema muestra un mensaje de error y no genera el PDF.
- **Resultado no deseado:** el documento se compila sin errores, pero algo no se ve como esperabas. El sistema no detecta este tipo de problema.

<div class="example-block">

**Ejemplos**

- Escribes `\dumentclass{article}` y la compilación falla.
  **Error de compilación**

- El PDF se genera pero el título aparece en minúsculas cuando querías mayúsculas.
  **Resultado incorrecto**

- Escribes el documento correctamente y el PDF muestra exactamente lo que esperabas.
  **Documento correcto**

</div>
