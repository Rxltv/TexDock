El entorno `itemize` crea una lista con viñetas. Cada elemento comienza con `\item` y el entorno debe cerrarse después del último elemento.

```latex
\begin{itemize}
  \item Cuaderno
  \item Lápiz
\end{itemize}
```

No se escriben las viñetas manualmente: LaTeX las genera.
