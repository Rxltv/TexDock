Cuando se abre un entorno con `\begin{nombre}`, LaTeX espera que más adelante aparezca `\end{nombre}` con el mismo nombre. Si el cierre usa un nombre distinto, el documento no compila.

El siguiente fragmento de código está incompleto. Le falta una línea para que sea un documento LaTeX válido:

```latex
\documentclass{article}
\begin{document}
Texto de prueba.
```

**Ejemplo:**

- `\end{article}` — Incorrecto. El nombre `article` no coincide con el entorno abierto (`document`).
- `\end{document}` — **Correcto.** `document` coincide exactamente con la apertura `\begin{document}`.
- `\close{document}` — Incorrecto. `\close` no es un comando de cierre de entorno en LaTeX.

Cada `\begin{nombre}` debe cerrarse con `\end{nombre}`. El nombre debe ser idéntico en ambos extremos.
