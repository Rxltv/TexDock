El trabajo con LaTeX sigue una secuencia de cuatro pasos:

1. **Escribir** o modificar el archivo `.tex` con el contenido y las instrucciones.
2. **Compilar** para procesar el archivo y generar el documento.
3. **Revisar** el resultado para ver si es el esperado.
4. **Corregir** o continuar añadiendo más contenido.

El archivo `.tex` es la fuente que puedes editar. El PDF es el resultado final. Si cometes un error, vuelves al archivo `.tex`, lo corriges y compilas de nuevo.
