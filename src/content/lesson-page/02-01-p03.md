El contenido visible del documento se escribe dentro del entorno `document`:

```
\begin{document}
Aquí va el contenido.
\end{document}
```

`\begin{document}` marca el inicio del cuerpo y `\end{document}` lo cierra. Todo lo que escribas entre estos dos comandos aparecerá en el documento final.

Sin el entorno `document`, LaTeX no tiene forma de saber qué parte del archivo debe mostrar.
