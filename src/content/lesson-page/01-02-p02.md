Es normal compilar un documento varias veces mientras se escribe. A menudo el resultado de una compilación no es el definitivo: puede faltar una actualización del índice, una referencia o la numeración de páginas.

Además, algunas funciones como el índice general o las referencias cruzadas necesitan una compilación adicional para actualizarse completamente.

<div class="example-block">

**Ejemplo de ciclo de corrección**

1. Escribir o modificar el código.
2. Compilar.
3. Leer el mensaje de error.
4. Corregir el error.
5. Revisar el PDF.
6. Repetir hasta que el documento esté correcto.

</div>
