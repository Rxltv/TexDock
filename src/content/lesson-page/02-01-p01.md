Todo archivo LaTeX se divide en dos zonas: el preámbulo y el cuerpo. El preámbulo aparece antes de `\begin{document}` y reúne la configuración del documento: clase, paquetes, título, autor y definiciones globales. El contenido principal visible se escribe después, dentro del cuerpo.

<div class="doc-structure">
  <div class="ds-row ds-preamble">
    <div class="ds-zone">
      <span class="ds-label">PREÁMBULO</span>
      <span class="ds-desc">Configura el archivo</span>
    </div>
    <pre class="ds-code">\documentclass{article}
% \usepackage{...}
% \title{...}
% \author{...}</pre>
  </div>
  <div class="ds-row ds-boundary">
    <div class="ds-zone"><span class="ds-label">INICIO</span></div>
    <code class="ds-bcode">\begin{document}</code>
  </div>
  <div class="ds-row ds-body">
    <div class="ds-zone">
      <span class="ds-label">CUERPO</span>
      <span class="ds-desc">Contenido visible</span>
    </div>
    <pre class="ds-code">Texto visible.</pre>
  </div>
  <div class="ds-row ds-boundary">
    <div class="ds-zone"><span class="ds-label">FIN</span></div>
    <code class="ds-bcode">\end{document}</code>
  </div>
</div>

Antes de `\begin{document}` se configura el archivo; entre `\begin{document}` y `\end{document}` se escribe el contenido visible.
