LaTeX es un sistema de preparación de documentos. A diferencia de un procesador visual, el usuario escribe contenido estructurado y el sistema lo procesa para generar el documento final, normalmente en PDF.

La idea fundamental es que el usuario indica **qué representa cada elemento** (un título, una sección, una fórmula) y LaTeX se encarga de componerlo con la tipografía y el formato adecuados.
