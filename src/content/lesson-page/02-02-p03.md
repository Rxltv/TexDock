Las opciones se colocan entre corchetes, justo antes del argumento obligatorio entre llaves. En las clases estándar como `article`, los valores disponibles para el tamaño base son `10pt`, `11pt` y `12pt`. El valor predeterminado es `10pt`.

En la práctica siguiente, el código inicial usa `10pt`. El objetivo es cambiarlo a `12pt` para observar el efecto.
