El entorno `enumerate` numera automáticamente los elementos. Es apropiado cuando el orden comunica una secuencia o prioridad.

```latex
\begin{enumerate}
  \item Preparar el borrador
  \item Revisar el contenido
\end{enumerate}
```

Al mover un `\item`, LaTeX recalcula la numeración.
