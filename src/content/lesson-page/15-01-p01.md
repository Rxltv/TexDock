El Proyecto Final será una tarea académica en clase `article`. Debe reunir configuración en español, metadatos, resumen, índice, tres secciones, dos subsecciones, formato moderado, una lista anidada, matemáticas, ecuación numerada, tabla, figura, nota, referencias internas y dos fuentes.

```latex
\documentclass{article}
% Preámbulo
\begin{document}
% Contenido y bibliografía
\end{document}
```

Esta lista define el alcance; cada elemento se incorporará en una página posterior.
