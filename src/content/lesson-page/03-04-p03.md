Las tres líneas de la plantilla parecen iguales, pero cada una cumple una función distinta:

**Ejemplo:**

```latex
\usepackage[T1]{fontenc}
```

Salida de las fuentes.

```latex
\usepackage[utf8]{inputenc}
```

Codificación del archivo fuente.

```latex
\usepackage[spanish]{babel}
```

Idioma y convenciones del documento.

Las tres líneas cumplen funciones diferentes; no deben memorizarse como un bloque indistinguible.
