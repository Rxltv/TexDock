Una lista puede aparecer dentro de un `\item` de otra lista. El entorno interior debe cerrarse antes que el exterior.

```latex
\begin{itemize}
  \item Materiales
    \begin{itemize}
      \item Papel
    \end{itemize}
\end{itemize}
```

La sangría del código ayuda a leer la jerarquía, aunque no sustituye los cierres.
